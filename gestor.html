Como achar o seu link

  1. Entre no Perfil da Empresa no Google (pesquise o nome da pizzaria logado na conta dona do perfil).
  2. Clique em “Pedir avaliações” e copie o link curto (g.page/r/…).
  3. Ou use só o Place ID (começa com ChIJ) pelo “Place ID Finder” do Google — o app monta o link sozinho.

Cartão por aproximação (NFC)

  1. Compre etiquetas ou cartões NFC NTAG213 ou NTAG215 (baratos no Mercado Livre/Shopee).
  2. Instale o app gratuito NFC Tools no celular (Android ou iPhone).
  3. No app: Gravar → Adicionar registro → URL, cole o link acima e toque em Gravar, encostando o cartão no celular.
  4. Opcional: em Outros → Bloquear etiqueta para ninguém regravar (é permanente).
  5. Cole o cartão no balcão ou na caixa da pizza, junto com o QR code impresso — quem não tiver NFC usa a câmera.
